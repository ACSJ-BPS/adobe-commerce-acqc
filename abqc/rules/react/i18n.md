# React — Internationalization

> Part of [React](./README.md).

## Never hardcode UI strings — all visible text must be externalized for i18n [error] [i18n, a11y]

Hardcoded string literals baked into JSX are un-localizable and fail Adobe's G11n requirements. All user-visible copy — labels, tooltips, error messages, button text, aria labels — must be stored in a message catalog and accessed via an i18n hook or function. React Spectrum and React Aria provide i18n primitives (`useMessageFormatter`, `I18nProvider`); use them. This rule also applies to `aria-label` props: never hardcode English-only ARIA labels in production components. Source: DXTS coding guidelines, Adobe G11n requirements.

### Check
```yaml
type: builtin
id: hardcoded-ui-string
files: ["**/*.{jsx,tsx,js,mjs,cjs}"]
```

### Bad
```jsx
<Button>Submit order</Button>
<ActionButton aria-label="Close dialog">
  <Icon />
</ActionButton>
```

### Good
```jsx
import { useMessageFormatter } from '@adobe/react-spectrum'
import messages from '../messages/en-US.json'

function SubmitButton () {
  const format = useMessageFormatter(messages)
  return <Button>{format('submit_order')}</Button>
}

function CloseButton () {
  const format = useMessageFormatter(messages)
  return <ActionButton aria-label={format('close_dialog')}><Icon /></ActionButton>
}
```
